# Minerva

Minerva is the instructional-design orchestration ecosystem: a conversational director and thought partner that helps clients turn learning or performance needs into validated instructional-production packages by coordinating specialist production systems.

This repository holds Minerva’s product vision and shared ecosystem architecture. Specialist systems retain ownership of their production logic and detailed artifacts.

## Current State

**Phase:** Shared Architecture Approved → Core Platform & Capability Architecture

The approved shared architecture defines canonical project state, specialist interfaces, orchestration, the unified group-chat/progressive-left-frame UX behavior, and state-to-UX mapping.

**Next action:** define **03 — Minerva Core Platform & Capability Architecture** before prototype implementation. This work must establish subject-agnostic project bootstrap, the shared truth Minerva gathers before specialist selection, a specialist framework and capability registry, engine-to-specialist capability inheritance, extensibility rules for future specialists, and multi-specialist conversation behavior. The Tutor.com project remains a validation case, not the prototype architecture.
